A museum label from the year 3000, placed next to an ordinary object from today: a pine-shaped car air freshener. The curators of the future are confident it is a real pine tree, ritually shrunk and hung in vehicles so the car would smell of forest. Sacrificed daily; the forest never noticed.

## Run it

```sh
node main.ts
```

Writes the label to `/output/entry.txt` (180 characters) and prints it to stdout.
